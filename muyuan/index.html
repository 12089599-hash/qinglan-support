反馈游戏问题

遇到闪退、画面异常或进度问题时，请写明设备型号、iOS 或 iPadOS 版本、游戏版本，以及问题出现前的操作。能稳定重现时，请一并说明复现步骤。

给开发者发邮件　·　提交公开问题

公开工单对所有人可见。涉及个人信息、截图或存档文件时，可通过邮件联系。

如何备份和恢复进度？

打开游戏右上角的「设置」，选择「导出存档」，把 JSON 文件保存到你选择的位置。更换设备或删除应用前，可以先导出一份备份。

恢复时，在「设置」中选择「导入存档」，选取备份文件。游戏会展示这份存档的角色和进度，点击「确认恢复」后才会写入。

存档保存在什么地方？

角色、装备、设置及战斗进度默认保存在设备上。如需了解文件导出和数据删除，请查看《暮渊旅团》隐私政策。
