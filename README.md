# 青岚洞府公开支持

本仓库只用于托管青岚洞府的公开支持页面、隐私政策和问题工单。

- 支持首页：https://12089599-hash.github.io/qinglan-support/
- 隐私政策：https://12089599-hash.github.io/qinglan-support/privacy/
- 问题反馈：https://github.com/12089599-hash/qinglan-support/issues

游戏源码、服务配置、密钥和内部运营资料不在本仓库中。

## 联系方式维护

- 对外统一使用“青岚洞府”或“青岚洞府支持”品牌署名。
- 公开工单只用于不含个人信息的一般问题；账号删除与隐私咨询通过支持页中的邮箱联系。
- 联系方式以支持首页的 `#contact` 区域为入口。变更邮箱前，必须验证新邮箱能接收和回复玩家邮件，且发件人名称、地址、回复地址及签名不包含个人身份信息。
- 更换邮箱时同步更新首页、隐私政策、应用内帮助及商店支持资料；验证游戏内删除入口和邮件删除渠道均可用后，再移除旧邮箱的公开展示。旧邮箱应继续处理过渡期间的请求。
